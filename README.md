# IR Project — Education Domain (PySpark & Retrieval System)

Modular workspace organized by project responsibilities according to `IR_Project_Requirements_and_Expected_Outputs_Fall2026.pdf` (Education Version, dataset `d:\3. Education`).

## Project Structure

| Folder / File | Responsibility | Status |
|---|---|---|
| `01_tokenization_positional_index/` | **Tokenization & Positional Index** (PySpark) | Implemented |
| `02_tf_df_idf/` | **TF, DF & IDF** matrices | Starter template |
| `03_tfidf_normalization/` | **TF-IDF & Vector Normalization** | Starter template |
| `04_phrase_search_similarity/` | **Phrase Search & Cosine Similarity** | Starter template |
| `05_boolean_search/` | **Boolean Search (`AND`, `AND NOT`)** | Starter template |
| `06_integration_testing_docs/` | **Integration, Testing & Part C Docs** | Test suite + templates |
| `output/` | Generated index artifacts (`json`, `jsonl`, `csv`, `txt`) | Generated by Module 01 |

## Quick Start
```bash
# Run Tokenization & Positional Index (Module 01)
python main.py

# Run verification tests
python -m unittest discover -s 06_integration_testing_docs -p "test_*.py" -v
```
